# Decisões e relatórios de adoção

> [🇺🇸 English](README.md) · 🇧🇷 Português

Registros que explicam *por que* o framework é como é, ao contrário das specs em
[`specs/`](../../specs), que dizem *o que* cada versão entregou.

| Arquivo | O que é |
|---|---|
| [`DEMANDA-PARTIU.md`](DEMANDA-PARTIU.md) | O relatório de adoção do Partiu, o primeiro app real portado do Next.js: os dez atritos que encontrou e o que cada um mudou no framework. A tabela "Quem usa" do README aponta para cá. |

As notas de trabalho do mantenedor que as specs 159–164 citam (o plano *Tokens 70* e o prompt
de sessão) e a apresentação da análise NestJS ficam nesta pasta no checkout de um mantenedor,
mas não são publicadas; as specs e o `CHANGELOG.md` registram o que saiu delas.
