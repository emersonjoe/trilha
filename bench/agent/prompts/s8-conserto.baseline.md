Este app em Go puro (net/http) tem três defeitos e os testes dele apontam: duas rotas registradas para o mesmo caminho (o servidor quebra ao subir), um formulário que sai sem o token CSRF verificado no POST e uma validação que aceita o nome vazio. Conserte os três — sem enfraquecer a validação nem dispensar o CSRF — até gofmt, go vet ./... e go test ./... ficarem verdes. O cadastro de contas em /contas precisa funcionar de ponta a ponta, como um navegador usa: criar uma conta pelo formulário e ver o erro por campo quando falta o nome.
