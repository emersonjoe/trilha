Adicione um cadastro completo de Produtos a este app em Go puro (net/http + html/template): a API JSON (GET /api/produtos lista, POST /api/produtos cria a partir do JSON {"nome", "preco"} e responde 201; 422 quando inválido, com os erros por campo) e a página /produtos com o formulário — nome obrigatório e preço maior ou igual a zero, mensagens por campo —, tudo guardado em memória. Escreva um teste da rota e da página com httptest e deixe go vet ./... e go test ./... verdes.
